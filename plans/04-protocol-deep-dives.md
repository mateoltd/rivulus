# 04 — Protocol Deep Dives (normative for agents)

Conventions: short lib names (`gateway::`, `rest::`, `model::`, `common::`, `cache::`). Error = `common::Error`.

## A. Gateway (v10, JSON + zlib-stream only v1)
- Bootstrap: types live in `model::gateway_bot::{GetGatewayBotResponse, SessionStartLimit}`; caller injects via `gateway::Bootstrap` trait. `gateway` has NO `rest` dep. Cache `url`; after READY also cache `resume_gateway_url` — ALL resumes/reconnects use `resume_gateway_url`, never the cached `url`.
- Connect URL (exact): `wss://gateway.discord.gg/?v=10&encoding=json&compress=zlib-stream`. `compress` is a QUERY PARAM, not an `Identify` field — `Shard::url()` builds it; mock gateway asserts the query param. `session_start_limit.remaining == 0` => sleep `reset_after` before ANY Identify (else 4008 + burn).
- Identify extras: `large_threshold` 50-250, `properties { os, browser: "rivulus", device: "rivulus" }`, first heartbeat jittered (`rand * interval`). `op4 VoiceStateUpdate` (gateway voice join): v1 only FORWARDS `VOICE_STATE_UPDATE`/`VOICE_SERVER_UPDATE` as `model::Event`; never connects (voice deferred D6).
- Opcodes: 0 Dispatch, 1 Heartbeat, 2 Identify, 3 PresenceUpdate, 4 VoiceStateUpdate, 6 Resume, 7 Reconnect (server asks reconnect), 8 RequestGuildMembers, 9 InvalidSession (`d: bool` resumable), 10 Hello, 11 HeartbeatAck. (No voice ops here.)
- Flow: `Hello { heartbeat_interval, _trace }` -> `Identify { token, intents: string-bits, properties { os, browser="rivulus", device="rivulus" }, compress? (zlib-stream), shard? [id,total], presence? }` -> `Ready { v, session_id, resume_gateway_url, user, guilds[] (unavailable), shard?, application }` -> heartbeats `op1 { d: seq|null }` every interval with jitter; `op11` updates `latency`; `op0 { t, s, d }` bumps `seq` ONLY on dispatch.
- Intents (exact bits, `gateway::Intents` bitflags, serde as needed): GUILDS 1<<0, GUILD_MEMBERS 1<<1*, GUILD_MODERATION 1<<2, GUILD_EMOJIS_AND_STICKERS 1<<3, GUILD_INTEGRATIONS 1<<4, GUILD_WEBHOOKS 1<<5, GUILD_INVITES 1<<6, GUILD_VOICE_STATES 1<<7, GUILD_PRESENCES 1<<8*, GUILD_MESSAGES 1<<9, GUILD_MESSAGE_REACTIONS 1<<10, GUILD_MESSAGE_TYPING 1<<11, DIRECT_MESSAGES 1<<12, DIRECT_MESSAGE_REACTIONS 1<<13, DIRECT_MESSAGE_TYPING 1<<14, MESSAGE_CONTENT 1<<15*, GUILD_SCHEDULED_EVENTS 1<<16, AUTO_MODERATION_CONFIGURATION 1<<20, AUTO_MODERATION_EXECUTION 1<<21, GUILD_MESSAGE_POLLS 1<<24, DIRECT_MESSAGE_POLLS 1<<25. Aliases (discord.js compat): `GUILD_BANS = GUILD_MODERATION`, `GUILD_EXPRESSIONS = GUILD_EMOJIS_AND_STICKERS`. `*` privileged -> `4014 help()` text + docs portal steps. `presences: true` in op8 REQUIRES `GUILD_PRESENCES` intent (validate client-side).
- GuildMembers chunk: `op8 { guild_id, query=""|string, limit, presences?, user_ids?, nonce }` -> `GUILD_MEMBERS_CHUNK { guild_id, members[], chunk_index, chunk_count, nonce, not_found?, presences? }` reassembly by `(nonce, guild_id)`: buffer out-of-order `chunk_index`, validate nonce, 10s timeout then evict + surface `not_found` ids. `limit: 0 + query: ""` = request-all-members. Ready barrier: `ClusterReady` only after ALL `ShardReady` + `guilds_available == expected` (30s timeout, else warn + proceed with count). `GUILD_CREATE` unavailable->available dance; `GuildUnavailable` vs `GuildDelete { unavailable? }` distinguished.
- Close codes (exhaustive, 4007 CORRECTED — never Resume on 4007): 4000/4001/4002/4003/4005 => Resume op6 if session+seq else fresh Identify; 4004/4010/4011/4012/4013/4014 => fail-fast `ShardDeath` + `help()` (4010: shard math + multiple-of-N; 4014: portal privileged-intent steps), NO retry; 4006 => fresh Identify immediately; 4007 (bad seq) => fresh Identify after 1-5s backoff (NEVER Resume — session seq is poisoned); 4008 => backoff 5s*attempt + `SendQueue` throttle; 4009/op7/transport-drop with seq+session => Resume op6 (`{token, session_id, seq}`) with exp backoff 1s->120s jitter; InvalidSession `d:true` => Resume after 1-5s, `d:false` => fresh Identify after 1-5s. `tests/gateway_resume.rs` MUST include `invalid_seq_fresh_identifies` case.
- Sharding: `shard_id = (guild_id >> 22) % total`; identify buckets `key = shard_id % max_concurrency`, 1 identify/5s/key, ordered start; large-bot (>150k) multiple-of-N via 4010; `GET /users/@me/guilds?shard=N` for large bots.
- Send ratelimit: <=120 cmds/min/shard via central `gateway::SendQueue` token bucket (presence <=5/20s included). No direct `send()` bypass.
- Transport: `tokio-tungstenite` v1 baseline (owns `Message::Text(String)` — accept per-message owned alloc; optimize count/size). P3 spike evaluates `tokio-websockets` Bytes; only one ships. `zlib-stream`: incremental `flate2` (miniz_oxide) decoder per connection, `Z_SYNC_FLUSH 00 00 FF FF` suffix may split across frames -> resync buffer; cap `max_decompressed_bytes_per_frame = 256 KiB` (else close+resume); `reset()` on reconnect. No per-message-deflate. No zstd v1.
- Presence: `op3 { since, activities[], status, afk }`. Watchdog: miss 2 ACKs -> close + resume path. Module split: `gateway/src/{shard.rs, cluster.rs, session.rs, compression.rs, intents.rs, opcodes.rs, queue.rs}`; dispatch enum lives in `model::Event`.
- Header peek: parse `op/t/s` via `common::json::RawValue` then full owned `model::Event`. `Event: 'static + Send + Sync`.

## B. REST (HTTP API v10, `https://discord.com/api/v10`, `rest::`)
- `rest::Client` wraps single `reqwest::Client` (rustls-manual-roots, pool 32 idle/host, 15s default timeout, webhook-exec 30s). `Authorization: Bot <SecretString>`, `Content-Type: application/json`, `User-Agent: DiscordBot (rivulus, <ver>)`. Request-id `uuid v4` short per call for tracing.
- Headers: `X-RateLimit-Limit/Remaining/Reset/Reset-After/Bucket/Scope/Global`. Prefer RELATIVE `Reset-After` over absolute `Reset` (clock-skew); on 429 the JSON `retry_after` is authoritative. Pre-emptive wait when `remaining==0` until `reset_after`; on 429 sleep `retry_after` (fractional) + penalty; `global=true` takes global lock. `Scope` trio: `user` (per-route, counted), `global` (global lock + counted), `shared` (NOT counted to ban-meter). Bucket key = `Route::method() + path_template() + major_id()` (webhook major = `id+token`; `POST /channels/:id/polls/:msg/expire` template) — `X-RateLimit-Bucket` authoritative once seen; ad-hoc `format!` routes FORBIDDEN. Global 50 rps/bot via `tokio::sync::Semaphore` refill window (documented contention note) — interactions endpoints exempt. Invalid-req 10k/10min: ban-meter counts 401/403/429 (excl. shared), warn 50%, error 80%; NEVER retry 401/403/404-webhook; 404 webhook => mark dead, stop use. Bucket state under `std::sync::Mutex` (short sections).
- Retry: idempotent GET/PUT/DELETE on 5xx/network/timeout only, jittered exp backoff max 3; NEVER auto-retry POST message-create (duplicate risk) without caller idempotency guard. Timeouts per-route override map.
- Routes (typed `rest::Route` + builders; full list P2 must implement): channels CRUD/typing/pins, messages CRUD/crosspost/bulk-delete/pins/reactions (all emoji routes), threads (create/join/leave/members/archive), polls (`/polls/expire`), guilds CRUD/channels/prune/mfa/widget/vanity/onboarding/welcome/welcome-screen/voice-regions/integrations, members (add/edit/nick/timeout/roles/prune/search), roles CRUD/positions, emojis/stickers guild-scoped + nitro-packs, invites CRUD, webhooks CRUD/execute/slack/github (`?wait&thread_id&with_counts`), application commands global+guild CRUD/bulk-overwrite + permissions, interactions callbacks/followups, scheduled-events, stage-instances, auto-mod rules, entitlements/SKUs/subscriptions, audit-log (`?before/after/limit`), soundboard, templates, current-user + `/users/@me/guilds`, OAuth2 invite helpers (in `common::oauth`). Multipart (`payload_json` FIRST part + files) for message-create/edit, webhook-exec, interaction-callback-with-files (`POST /interactions/{id}/{token}/callback`), sticker-create (form-fields variant for sticker upload); `attachment://` refs. Webhook-execute builder includes `thread_name` + `?wait&thread_id&thread_name&with_counts`. Webhook URL tokens are SECRETS: same `SecretString`/redaction as Bot token (Debug/logs/metrics never print them). `X-Audit-Log-Reason` 1-512 URL-encoded, validated client-side.
- Files: `rest/src/{client.rs, ratelimiter.rs, routes.rs, builders/*.rs, multipart.rs, audit.rs}`; errors map `{code,message,errors}` -> `common::Error::Rest{...}`. `ratelimiter.rs`: per-bucket `Mutex<BucketState>` + global token-bucket semaphore + sleep map; contention note: shard requests via `Semaphore(50)` refill 1s window, documented.

## C. Cache (`cache::`, dashmap6 locked)
- `trait Cache: Send+Sync`: guild/channel/role/member/user/message/thread/voice-state/presence inserts + get/remove/clear/stats. `InMemoryCache`: `dashmap6+foldhash` maps `Id -> Arc<T>`.
- Canonical interning (no duplication): `users: Map<UserId,Arc<User>>`; `Message { author_id: UserId }` + `author() -> Option<Arc<User>>` lookup; Member/Presence hold `user_id`, not `User`. Insert via `entry` API; eviction bounded.
- `cache::UpdateCache` centralized per-event: `cache/src/event/{guild,channel,member,message,role,thread,voice,presence,...}.rs` — one module per event family (mirrors twilight-cache-inmemory), never a `match Event` god-function. `ResourceType` bitflags (frozen P1a): `GUILD|CHANNEL|ROLE|MEMBER|USER|MESSAGE|REACTION|VOICE_STATE|PRESENCE|THREAD|THREAD_MEMBER|STAGE|SCHEDULED_EVENT|EMOJI|STICKER|INVITE|SOUNDBOARD|ENTITLEMENT|AUTOMOD`. `model::Partial` (frozen): `User|Channel|GuildMember|Message|Reaction|GuildScheduledEvent|ThreadMember` — opt-in `Partial::fetch(ctx)` (semaphore 10 + 5s timeout), NO global `lazy_fetch_partials` auto-spawn. Caps: per-channel `VecDeque<MessageId>` + `message_limit` (default 0=off), `member_high_water` LRU, presence/reaction default off. Sweeper: `tokio::interval(60s)` sharded `retain` by `last_access/max_age` (msg 1h, typing 10s), emits `cache_hit_ratio`; never blocks reads.
- Diffs: clone `cached: Option<Arc<T>>` BEFORE insert, emit `(old,new)`; compare by field equality on small types, never hash full guild; never clone full `Guild` on `MemberUpdate`.
- Partials: `model::Partial { User|Message|Channel|GuildMember|Reaction }` when dispatch refs uncached; `lazy_fetch_partials` bounded (semaphore + timeout), backpressured.
- Unknown enums: `ChannelType::Unknown(u8)` etc. via manual `Deserialize` round-trip (NOT `#[serde(other)]`). `Event::Unknown { payload }` capped at 8 KiB (truncate + count, never buffer-bomb). `Cache` trait is dyn-safe ONLY: sync fns, no generics, no `impl Stream` returns (P1a asserts `Arc<dyn Cache>` compiles).
